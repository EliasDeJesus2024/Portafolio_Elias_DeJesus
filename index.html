AI Capabilities and Limitations is an introductory course by Anthropic that explains how large language models work, what they can do well, and where they have limitations. It covers next-token prediction, model knowledge, working memory, and steerability, helping learners use AI more effectively and critically in work and studies.

Claude Code In Action

Claude Code in Action is an advanced course by Anthropic that teaches developers how to manage long-running AI coding tasks, automate repetitive workflows, and configure Claude Code for team collaboration. It covers autonomous sessions, custom skills, permission controls, hooks, scheduled routines, GitHub Actions, and code verification to ensure reliable results with less supervision.
